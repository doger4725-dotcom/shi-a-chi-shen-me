# 是啊，吃什么

安徽大学龙河校区第三食堂就餐决策项目：在预算和可用时间内，选一顿赶得上、吃得好的饭。

## 体验功能

- 按用餐时段、窗口、预算和等待上限筛选。
- TimeShift比较不同菜品的赶时间、省饭钱和综合备选，算入步行、等待、出餐、用餐和返回时间，展示返回时刻与推荐理由。候选不足时显示实际数量。
- “现在出发”每30秒按当前时间重算；新报数参与窗口等待估计。
- 抽卡结合时间、价格、口味和个人评分，公布每道菜的抽取概率。
- 吃完在“我的饭钱”打星、写评论：4～5星“出金了”，1～2星“歪了”，下次按新权重抽卡。
- 确认用餐后记录餐费，查看月度预算和剩余餐费。
- 基础营养搭配与搭配知识卡。
- “想吃什么”菜品心愿问卷：填写菜名、期望价格、餐段和口味，本机保存、修改，导出CSV表格或JSON备份后交给项目组汇总。

当前GitHub Pages版本提供以上功能。个人评价保存在当前浏览器；共享讨论、公开评价及DeepSeek需要另接服务器。

## 数据

2026年10月18日第三食堂现场照片录入98道午餐和24项加料。09号窗口当天11:30加入队伍，约11:38取餐，共8分钟，已包含出餐。

单次实测用于周末相近时刻的参考；其他时间显示对应的数据来源。早餐、晚餐及口味待补录。

## 看懂模型

先筛掉超预算、超等待上限或不能按时返回的菜品。对剩余菜品，按当前目标加权时间、价格与口味得到适合度s，再用`exp(6s)×个人评分系数`计算权重。全部合格菜品进入卡池，权重归一化为概率。

| 最近一次个人评分 | 权重系数 |
| --- | --- |
| 1星 | ×0.25 |
| 2星 | ×0.5 |
| 3星 / 未评价 | ×1 |
| 4星 | ×1.5 |
| 5星 | ×2 |

修改评价会替换系数。系数调整的是权重，最终概率还取决于整个卡池。比如两道菜权重原本同为10，一道评5星后为20，概率变成约66.7%和33.3%。

## 源代码

根目录是可直接发布的网页代码：

| 文件 | 用途 |
| --- | --- |
| index.html / styles.css | 页面内容和外观 |
| app.js / cards.css | 抽卡动画、筛选和账本交互 |
| model.js | 等待估算与预算计算 |
| decision.js / decision-ui.js | TimeShift和抽取概率 |
| preferences.js / preferences-ui.js | 个人评分、评论和权重调整 |
| survey.js / survey.css | 菜品问卷、本机保存和导出 |
| canteen-data.js | 真实窗口、菜价与实测记录 |
| nutrition.js / nutrition-ui.js | 基础搭配与助手页面 |

# 是啊，吃什么

安徽大学龙河校区第三食堂就餐决策项目：在预算和可用时间内，选一顿赶得上、吃得好的饭。

## 体验功能

- 按用餐时段、窗口、预算和等待上限筛选。
- TimeShift比较最快、省钱和综合方案，算入步行、等待、出餐、用餐和返回时间。
- 加权转盘根据时间、价格和口味调整概率，扇区大小与实际抽取概率一致。
- 确认用餐后记录餐费，查看月度预算和剩余餐费。
- 基础营养搭配与搭配知识卡。

当前GitHub Pages版本提供以上功能。共享讨论、五星评价及DeepSeek需要另接服务器。

## 数据

2026年10月18日第三食堂现场照片录入98道午餐和24项加料。09号窗口当天11:30加入队伍，约11:38取餐，共8分钟，已包含出餐。

单次实测用于周末相近时刻的参考；其他时间显示对应的数据来源。早餐、晚餐及口味待补录。

## 看懂模型

先筛掉超预算、超等待上限或不能按时返回的菜品。对剩余菜品，按当前目标加权时间、价格与口味得到适合度s，再用`exp(6s)`计算权重。前8道权重归一化后形成转盘概率。
